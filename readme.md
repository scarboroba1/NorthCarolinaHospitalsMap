# Hospitals per County in North Carolina 

## Intro
When you open this website, you will be greated with a map of North Carolina, specifically devided by county. Within each of these counties, you will notice a mark in each one of them signifying a location of a hospital. The more hospitals in a county, the darker the county. 

## Major Function
As for a major function, you will be able to visualize each county, as well as being able to click said hospital and learn its name. The darker the county, the more hospitals are located within it, allowing the user to see what counties have more hospitals than others. This essentially allows the user to see any hospital deserts across North Carolina. This could also be used by first responders. 

## Libraries 
Leaflet, Geojson, FontAwesome

## Data Sources
Hospitals across North Carolina.
